# Projeto expotech - V.I.S. — Versatile Intelligence System

O presente relatório tem como objetivo apresentar como foi planejado, desenvolvido e implementado o projeto V.I.S. (Versatile Intelligence System), criado para a ExpoTech 2026.2, que tem como tema “Missão 2050: Smart Home & Tecnologias do Futuro”.

A ideia do projeto surgiu a partir da inspiração em tecnologias de automação residencial que vemos em filmes, principalmente nos sistemas inteligentes utilizados por Tony Stark. Com base nessa referência, o grupo pensou em desenvolver uma solução que reunisse diferentes funcionalidades para facilitar o gerenciamento de uma casa em um único sistema.

O V.I.S. foi criado com a proposta de mostrar como diferentes tecnologias podem trabalhar juntas para tornar uma residência mais prática, organizada, confortável e sustentável.

Além de apresentar uma solução tecnológica, o projeto também foi uma oportunidade de colocar em prática os conhecimentos adquiridos ao longo do primeiro semestre da graduação. Durante o desenvolvimento, foram trabalhadas diferentes áreas, como programação, criação de interfaces, integração entre sistemas, automação de processos e eletrônica.
