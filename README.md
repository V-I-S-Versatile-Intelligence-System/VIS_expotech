# Projeto expotech - V.I.S. — Versatile Intelligence System
# Projeto ExpoTech 2026.2

Missão 2050: Smart Home & Tecnologias do Futuro

Sobre o projeto:

O presente projeto tem como objetivo apresentar como foi planejado, desenvolvido e implementado o V.I.S. (Versatile Intelligence System), criado para a ExpoTech 2026.2, cujo tema é "Missão 2050: Smart Home & Tecnologias do Futuro".

A ideia surgiu a partir da inspiração em tecnologias de automação residencial presentes em filmes, principalmente nos sistemas inteligentes utilizados por Tony Stark.

Com base nessa referência, o grupo idealizou uma solução capaz de reunir diferentes funcionalidades para facilitar o gerenciamento de uma residência em um único sistema.

O V.I.S. foi desenvolvido com a proposta de demonstrar como diferentes tecnologias podem trabalhar juntas para tornar uma residência mais prática, organizada, confortável e sustentável.

Além de apresentar uma solução tecnológica, o projeto representa uma oportunidade de colocar em prática os conhecimentos adquiridos durante o primeiro semestre da graduação, envolvendo áreas como programação, desenvolvimento de interfaces, integração entre sistemas, automação de processos e eletrônica.

Nossa visão para 2050:

Imagine uma residência na qual diferentes tecnologias trabalham em conjunto para tornar o cotidiano mais simples, eficiente e conectado.

Essa é a visão que inspira o V.I.S.

Acreditamos que o futuro das residências não está apenas em possuir dispositivos tecnológicos, mas em fazer com que eles trabalhem juntos para proporcionar experiências melhores às pessoas.
