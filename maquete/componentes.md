# Componentes da Maquete V.I.S.

## Projeto Smart Home 2050

A maquete V.I.S. foi desenvolvida para demonstrar a automação residencial por meio da integração entre eletrônica, programação e impressão 3D.

## Componentes utilizados

- **ESP32 DevKit:** microcontrolador responsável pelo sistema.
- **HC-SR04:** sensor ultrassônico para detectar a aproximação de veículos.
- **Servo SG90:** motor utilizado para movimentar o portão.
- **LEDs:** iluminação individual dos ambientes.
- **Resistores:** proteção dos LEDs e divisor de tensão do sensor.
- **Fontes de alimentação:** fornecimento de energia aos componentes.
- **Jumpers e protoboard:** conexões elétricas e testes.

## Funcionalidades da maquete

- Controle individual das luzes.
- Acionamento de todas as luzes.
- Abertura e fechamento automatizados do portão.
- Detecção de aproximação por sensor ultrassônico.
- Iluminação da garagem sincronizada com o portão.
- Comunicação Wi-Fi com o ESP32.
- Controle por painel web na rede local.

## Tecnologias utilizadas

- Arduino IDE
- Linguagem C++
- ESP32
- Comunicação HTTP
- Impressão 3D

O projeto foi desenvolvido para a ExpoTech 2026.
