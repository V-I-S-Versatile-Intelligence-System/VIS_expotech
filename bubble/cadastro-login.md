# Cadastro, Login e Navegação — V.I.S.

## Objetivo

O sistema de cadastro e login foi desenvolvido na plataforma Bubble para permitir que os usuários acessem a interface do V.I.S. Smart Home 2050.

A proposta é oferecer uma experiência organizada, com páginas e funcionalidades acessíveis por meio de uma navegação intuitiva.

## 1. Cadastro de usuários

Foi desenvolvida uma interface de cadastro utilizando os elementos visuais e recursos de autenticação disponíveis no Bubble.

O cadastro permite que novos usuários criem uma conta para utilizar a plataforma.

## 2. Login

A interface de login permite que usuários cadastrados acessem o sistema utilizando suas credenciais.

O Bubble oferece recursos próprios para gerenciar a autenticação e as sessões dos usuários.

## 3. Navegação entre páginas

O site foi organizado para facilitar o acesso às principais funcionalidades.

Entre as áreas desenvolvidas estão:

- Página inicial.
- Cadastro e login.
- Painel de controle da residência.
- Gerenciamento de receitas e despesas.
- Consulta de consumo de água e energia.
- Relatórios.
- Informações sobre o projeto V.I.S.

## 4. Workflows

Foram utilizados workflows do Bubble para configurar ações e interações da interface.

Esses recursos permitem associar eventos, como cliques em botões, às funcionalidades e à navegação do sistema.

## 5. Experiência do usuário

A interface foi planejada com foco em:

- Facilidade de navegação.
- Organização das funcionalidades.
- Botões e elementos interativos.
- Visual moderno e intuitivo.
- Acesso às informações em diferentes páginas.

## Resultado

A criação das telas de cadastro, login e navegação contribuiu para a organização da plataforma V.I.S., permitindo que os usuários encontrem as funcionalidades do sistema de maneira simples e prática.
