# Relatórios e Consultas — V.I.S. Smart Home 2050

## Objetivo

O módulo de relatórios e consultas do V.I.S. foi desenvolvido na plataforma Bubble para facilitar a visualização e o acompanhamento das informações relacionadas ao gerenciamento residencial.

A proposta é permitir que o usuário consulte dados de consumo, acompanhe suas despesas e utilize essas informações para organizar melhor seus gastos.

## 1. Relatórios de consumo

A interface possui uma área dedicada à apresentação de informações sobre o consumo de água e energia elétrica.

O sistema foi planejado para facilitar:

- Consulta dos gastos de água.
- Consulta dos gastos de energia.
- Visualização de valores registrados.
- Acompanhamento das informações por período.
- Análise dos custos da residência.

## 2. Sistema de pesquisa

Foram trabalhados recursos de pesquisa para permitir que o usuário encontre informações específicas.

Entre as possibilidades de consulta estão:

- Pesquisa por período.
- Consulta de registros financeiros.
- Visualização de dados de consumo.
- Acompanhamento de informações anteriores.

## 3. Histórico de informações

O histórico foi considerado como um recurso importante para a organização dos registros do sistema.

A proposta é permitir que o usuário acompanhe informações anteriores e consulte dados sem depender apenas dos valores apresentados na tela principal.

O registro de eventos de acionamento dos botões também foi estudado como uma possibilidade de ampliação do histórico.

## 4. Planejamento de gastos

Uma das propostas da interface é ajudar o usuário a compreender quanto está gastando e quanto poderá gastar.

Para isso, os relatórios podem servir como apoio para:

- Acompanhamento das despesas.
- Comparação de períodos.
- Planejamento financeiro.
- Identificação de oportunidades de economia.

## 5. Desenvolvimento no Bubble

Durante o desenvolvimento, foram utilizados e estudados recursos como:

- Elementos de texto e exibição de informações.
- Campos de pesquisa.
- Workflows para interações.
- Recursos de banco de dados.
- Componentes de apresentação de registros.

## Resultado

O módulo de relatórios e consultas contribuiu para tornar a interface V.I.S. mais completa, reunindo recursos de acompanhamento de consumo e gerenciamento de informações residenciais.

Funcionalidades adicionais de histórico automático e análises avançadas poderão ser incorporadas em versões futuras.
