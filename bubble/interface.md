# Interface V.I.S. — Smart Home 2050

## Apresentação

A interface do V.I.S. (Versatile Intelligence System) foi desenvolvida utilizando a plataforma Bubble, com o objetivo de oferecer uma experiência simples, moderna e intuitiva para o gerenciamento de uma residência inteligente.

O site foi planejado para centralizar diferentes funcionalidades em um único ambiente digital.

## Objetivo da interface

Facilitar o gerenciamento residencial por meio de uma plataforma acessível, permitindo que os usuários controlem e consultem informações relacionadas à sua residência.

## Desenvolvimento

A interface foi construída utilizando recursos visuais e workflows da plataforma Bubble, permitindo desenvolver as funcionalidades sem a necessidade de programação tradicional.

## Principais funcionalidades

- Cadastro e login de usuários.
- Navegação entre páginas do sistema.
- Controle manual da iluminação dos ambientes.
- Acionamento de todas as luzes.
- Cadastro de receitas e despesas.
- Consulta de consumo de água e energia.
- Relatórios e pesquisas por período.
- Páginas informativas sobre o projeto e seus benefícios.

## Tecnologias utilizadas

- Bubble
- Banco de dados do Bubble
- Workflows
- Elementos visuais e componentes de interface

## Integração com a maquete

O projeto prevê a comunicação entre a interface desenvolvida no Bubble e a automação física controlada pelo ESP32.

A integração pode utilizar requisições HTTP e ferramentas como o n8n para conectar o site aos dispositivos da maquete.

## Resultado

O desenvolvimento da interface permitiu criar uma plataforma digital para apresentar e gerenciar as principais funcionalidades propostas para o projeto V.I.S. Smart Home 2050.
