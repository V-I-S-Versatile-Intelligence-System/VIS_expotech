# Banco de Dados e Controle Financeiro — V.I.S.

## Objetivo

O sistema de gerenciamento financeiro do V.I.S. Smart Home 2050 foi desenvolvido na plataforma Bubble para facilitar a organização de receitas e despesas relacionadas à residência.

A proposta é permitir que o usuário registre informações financeiras e consulte os valores por meio de uma interface simples e organizada.

## 1. Banco de dados

O Bubble disponibiliza um banco de dados integrado, utilizado para estruturar as informações do sistema.

No módulo financeiro, são consideradas informações como:

- Tipo de movimentação: receita ou despesa.
- Descrição da movimentação.
- Valor registrado.
- Data do lançamento.
- Categoria da movimentação.

Esses campos representam a estrutura de informações necessária ao controle financeiro.

## 2. Cadastro de receitas

A interface de receitas permite registrar valores recebidos pelo usuário.

O objetivo é organizar as entradas financeiras e facilitar o acompanhamento dos recursos disponíveis.

## 3. Cadastro de despesas

O módulo de despesas permite registrar os gastos relacionados à residência.

Os lançamentos podem ser utilizados para acompanhar os custos e identificar as principais categorias de despesas.

## 4. Workflows

Os workflows do Bubble são utilizados para configurar as ações relacionadas aos formulários.

Entre as ações previstas estão:

- Receber os dados preenchidos.
- Validar as informações.
- Registrar as movimentações.
- Consultar os lançamentos cadastrados.

## 5. Consulta financeira

O sistema foi planejado para facilitar a visualização das receitas e despesas, permitindo ao usuário acompanhar suas movimentações financeiras.

## Resultado

O módulo financeiro do V.I.S. reúne recursos de cadastro e organização de receitas e despesas, contribuindo para uma experiência de gerenciamento residencial mais completa.
