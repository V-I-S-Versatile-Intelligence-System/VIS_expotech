# Monitoramento de Água e Energia — V.I.S.

## Objetivo

O módulo de consumo do V.I.S. Smart Home 2050 foi desenvolvido no Bubble para facilitar o acompanhamento dos gastos de água e energia elétrica de uma residência.

A proposta é oferecer informações organizadas que auxiliem o usuário no controle do consumo e no planejamento de suas despesas.

## 1. Consumo de energia elétrica

A interface apresenta uma área dedicada ao acompanhamento do consumo de energia.

Entre os recursos planejados estão:

- Visualização do consumo em kWh.
- Consulta dos valores estimados em reais.
- Acompanhamento por período.
- Comparação dos gastos.
- Consulta ao histórico de consumo.

## 2. Consumo de água

Foi desenvolvida uma área para o acompanhamento do consumo de água.

O módulo foi planejado para apresentar:

- Quantidade de água consumida.
- Estimativa de custos.
- Consulta por período.
- Histórico dos registros.
- Informações para auxiliar na economia de água.

## 3. Registro e simulação

Durante o desenvolvimento, foram exploradas formas de registrar e apresentar os dados de consumo.

Uma das propostas foi a utilização de valores simulados para representar o funcionamento de uma residência inteligente, sem depender de medidores físicos de água e energia.

A automação da geração desses valores constitui uma funcionalidade a ser validada separadamente.

## 4. Relatórios e consultas

A interface contempla recursos para consultar informações de consumo e acompanhar os gastos da residência.

O objetivo é permitir que o usuário:

- Consulte os gastos registrados.
- Pesquise informações por período.
- Acompanhe a evolução do consumo.
- Avalie quanto está gastando.
- Utilize os dados para planejar seus gastos futuros.

## 5. Tecnologias utilizadas

- Bubble
- Elementos visuais
- Workflows
- Recursos de banco de dados
- Componentes de apresentação de informações

## Resultado

O desenvolvimento desse módulo ampliou as funcionalidades do V.I.S., incorporando recursos de acompanhamento de água e energia à interface de gerenciamento residencial.

O monitoramento por sensores físicos e a atualização totalmente automática dos dados são possibilidades de evolução do projeto.
